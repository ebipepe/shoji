HTTPS を復号しないホスト

銀行・決済・証明書ピンニングを使うアプリ等。ドメイン単位のブロックは引き続き有効です。 国内外の主な銀行・証券・決済・パスワード管理サービス（約 100 件）は、ここに追加しなくても常に対象外です。 一覧を表示

自動で除外されたホスト

証明書を受け付けなかったため自動的に HTTPS 復号の対象外にしたアプリ・ホストです（他のブラウザでのフィルタリングには影響しません）。

フィルタリスト

「迷惑要素」のリストは、広告ではないものの邪魔になる要素（Cookie の同意バナー、ページ内ポップアップ、チャットなどのウィジェット等）を隠します。 サイトによっては表示が崩れることがあるため、最初はオフにしています。崩れたときは「フィルタリングログ」で原因のルールを確認できます。

ユーザールール

ページ上で Alt+Shift+H を押すと「要素の選択ブロック」が起動し、隠したい部分をクリックするだけでここにルールが追加されます。 不要になったルールは、この欄から行を消して保存すれば取り消せます。

URL チェック

URL がブロックされるか、どのルールに一致したかを確認できます。


    

  







  

    
1

      HTTPS フィルタリング用の証明書をインストール 
      
YouTube の動画広告除去・要素非表示・ステルスモードなど、HTTPS サイトの中身を処理するのに必要です。この PC 専用に生成された証明書で、外部には送信されません。

       証明書をダウンロード
      
Firefox は起動時に、Windows の証明書を使う設定を自動で入れます（Firefox の再起動後に有効）。

    

    
2

      Windows のプロキシ設定 
      
ブラウザと、システムのプロキシ設定に従うアプリの通信をフィルタします。既定では「自動構成スクリプト」方式なので、Shoji が止まっていても自動で直接接続に戻り、ネットが切れません。終了時には元の設定に戻ります。

       
    

    
★

      Windows の起動時に Shoji を開始 
      
サインインすると自動でタスクトレイに常駐します（現在のユーザーのみ・管理者権限は不要）。

      
    

    
3

      DNS フィルタリング（アプリ内広告） 
      
PC の DNS を本ソフトに向け、プロキシを使わないアプリの広告・トラッカーも名前解決の段階で止めます。管理者権限が必要なので set_dns.bat を右クリック →「管理者として実行」してください。元に戻すときは reset_dns.bat。

       
    

    
4

      スマホ・タブレットのアプリ内広告もブロックする（任意）
      
設定タブではなく data\config.json の dns.listen_host と proxy.listen_host を 0.0.0.0 にして再起動し、スマホの Wi-Fi 設定で DNS をこの PC の IP アドレスにします。HTTPS フィルタリングも使う場合は Wi-Fi のプロキシをこの PC の  に設定し、ブラウザで http://shoji.blocker/cert を開いて証明書をインストールします。
